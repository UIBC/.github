# Support

## Where to ask

| What you need | Where |
|---|---|
| A question about the spec's meaning | [Discussions on `spec`](https://github.com/UIBC/spec/discussions) |
| Something looks wrong in a repository | an issue on that repository |
| A run result you want recorded | a receipt + the *Independent run receipt* issue template on `vectors` |
| A security report | the private channel described in [`SECURITY.md`](SECURITY.md) — do not open a public issue |

## What you can expect

One maintainer, best effort, no response-time commitment. Questions that come with a reproducible command get answered first, because they can be answered with evidence instead of opinion.

## What is not offered

- No certification, approval, endorsement, or "UIBC compliant" marking of any product.
- No commercial support, no SLA, no consulting engagement under this organisation's name.
- No verdict on whether a particular agent is safe. UIBC checks bytes; the world is not bytes.

## Before you ask

Run the two commands on the front page. Most "it does not work" reports resolve to one of: a Python version below 3.11, `uibc-core` not installed from PyPI, or a Windows checkout whose line endings were rewritten (see `vectors/README.md`).
